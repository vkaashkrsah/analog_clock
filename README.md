# Analog Clock

A modern, customizable analog clock project built with two implementations: Vanilla JavaScript and React with Node.js.

## Project Structure

```text
analog_clock/
├── web-basic/
│   ├── index.html
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── script.js
├── react-node/
│   ├── client/
│   └── server/
└── README.md
```

## Implementations

### 1. Vanilla JavaScript
Built using:
- HTML5
- CSS3
- Vanilla JavaScript

Features:
- Real-time analog clock
- Hour, minute, and second hands
- Digital time and date
- Multiple numeral styles
- Multiple clock hand styles
- Customizable dial patterns
- Watch and background themes
- Custom color selection
- Responsive design

**Run locally:** Open `web-basic/index.html` in your browser.

### 2. React and Node.js
Planned implementation using:
- React
- Node.js
- Express.js

Development is planned.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/vkaashkrsah/analog_clock.git
cd analog_clock
```

Open the Vanilla JavaScript version in your browser:

```bash
open web-basic/index.html
```
